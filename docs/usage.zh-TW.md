# 使用方式

下面的 `mapedit <指令>`，在 repo 根目錄是 `pnpm mapedit <指令>`，在其他地方是
`node <repo 路徑>/packages/cli/dist/index.js <指令>`。見[安裝](installation.zh-TW.md)。

## 啟動編輯器

Windows 上雙擊 `啟動地圖編輯器.bat`（見[安裝](installation.zh-TW.md#windows啟動檔)）。任何系統：

```sh
mapedit dev [--port <port>] [--mock] [--open] [--projects <資料夾> [--project <名稱>]]
```

| 選項                   | 作用                                                                     |
| ---------------------- | ------------------------------------------------------------------------ |
| `--port <port>`        | 要監聽的連接埠，預設 `4790`。                                            |
| `--open`               | 用預設瀏覽器打開編輯器。                                                 |
| `--projects <資料夾>`  | 提供一整個資料夾的專案，可以在編輯器裡切換。                             |
| `--project <名稱>`     | 搭配 `--projects`：先打開哪個專案。沒指定時打開上次開的專案，再沒有就用資料夾名稱排第一個的。 |
| `--mock`               | 改用固定的測試場景，只存在記憶體裡。給前端開發用，見[開發](development.zh-TW.md)。 |

沒加 `--projects` 時，`dev` 提供目前目錄的專案。伺服器會印出 `mapedit listening at http://127.0.0.1:4790`，
而且只接受本機連線。這個網址提供瀏覽器編輯器、MCP `screenshot` 用的 `/render` 截圖頁面，以及位在 `/mcp`
的 MCP。網址加上 `?map=<id>` 可以直接打開某一張地圖。

編輯器開著時，Agent 改檔案，畫面會即時更新。人在網頁上的修改會寫回 YAML，並保留註解。

## 專案資料夾

所有地圖專案都放在 `projects/` 裡，一個資料夾就是一個專案：有自己的 `project.yaml`、模組（`modules/`）
和地圖（`maps/`，一個專案可以有很多張）。專案之間的模組和地圖互不相通；材質目前是編輯器內建的一套，
所有專案共用。

- 在編輯器左上角的「專案」選單可以切換專案。Agent 透過 HTTP 的 MCP 操作的，也是目前開著的專案，
  所以 Agent 改的就是你看到的那個。
- 新增專案：`mapedit init projects/<名稱>`，或請 Agent 在 `projects/` 裡建立資料夾。游標移到「專案」選單上
  時，會重新讀取清單。
- `projects/` 不受 Git 管理，`更新.bat` 不會動到它。
- Windows 啟動檔發現 `projects/church` 不存在時，會把 `templates/church`（哥德式教堂的灰白模型，使用卡通渲染
  `style: toon`）複製過去；刪掉後再啟動就會拿到最新版。舊版放在旁邊 `../mapedit-maps` 的專案會自動搬成
  `projects/my-maps`。

專案和地圖選單、版次、連線狀態，以及語言切換（繁體中文或英文），都在左上角的標題欄。

## 編輯器操作

俯瞰模式的鏡頭從上方看整張地圖。

| 操作       | 做法                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 轉動鏡頭   | 右鍵拖曳                                                                 |
| 移動鏡頭   | 中鍵拖曳、在空地上左鍵拖曳，或 WASD／方向鍵                              |
| 縮放       | 滾輪（往游標的位置）                                                     |
| 對焦       | F：飛到選取的東西；沒有選取時看整張地圖                                  |
| 選取       | 點一下選整個結構，再點一次同一個結構裡的模組就只選那個模組               |
| 移動       | 拖曳結構或標記；預覽變紅就是放不下去，放開時不會套用                     |
| 旋轉       | R 轉 15 度（Shift+R 反方向），拖曳中也可以按                             |
| 刪除       | Delete 或 Backspace                                                      |
| 復原、重做 | Ctrl+Z；Ctrl+Y 或 Ctrl+Shift+Z（macOS 用 Cmd）                           |
| 退一步     | Esc：先取消拖曳，再取消點選的違規，最後取消選取                          |
| 切換專案   | 左上角「專案」選單                                                       |
| 第一人稱   | V（見下面）                                                              |

第一人稱模式可以在地圖裡飛來飛去，只能看、不能編輯，但復原和重做仍然有效。可以穿過建築，但不會穿過地面。

| 操作       | 做法                                               |
| ---------- | -------------------------------------------------- |
| 看四周     | 移動滑鼠（瀏覽器沒有鎖定游標時，改用拖曳）         |
| 飛行       | WASD 或方向鍵                                      |
| 上升、下降 | 空白鍵、Shift                                      |
| 飛行速度   | 滾輪                                               |
| 回到俯瞰   | Esc 或 V                                           |

左邊的「違規」面板列出違規和檔案錯誤，編號和地圖上的旗子一致；點一下就飛過去，再點一次放開。
右邊的「修改紀錄」列出每一次修改（人或 Agent 做的都有），也有復原和重做按鈕。

### 修改的規則

- 拖曳時 x、z 會對齊 0.5 公尺的格子。高度設為自動的結構會貼合地形；標記會保持離地的高度。
- 每次放下，伺服器都會檢查。放下去會造成違規的話就拒絕，東西彈回原位。
- 結構和標記都是整個一起移動。結構裡的單一模組，或已經接到別的結構上的結構，不能單獨移動；
  請移動它的根結構。單一模組可以單獨刪除。
- 專案裡有檔案讀不了的時候，編輯器會顯示檔案錯誤，修好之前不接受任何修改。
- 復原和重做涵蓋整個專案，包含 Agent 做的修改。人和 Agent 改到同一個東西時，以後改的為準，並跳出提示。

## CLI 指令

`check`、`export` 和 `mcp` 要在專案資料夾裡執行。

| 指令                                        | 作用                                                               |
| ------------------------------------------- | ------------------------------------------------------------------ |
| `mapedit init [資料夾]`                     | 建立專案：七種基本模組、一張範例村莊地圖、`AGENTS.md`、Claude Code skill 和 MCP 設定 |
| `mapedit dev [選項]`                        | 啟動編輯器伺服器（見上面）                                         |
| `mapedit check [--map <id>] [--json]`       | 檢查地圖的違規和檔案錯誤                                           |
| `mapedit export [--map <id>] --out <資料夾>` | 每張地圖寫出一個 `<地圖 id>.glb`。見[匯出](exporting.zh-TW.md)    |
| `mapedit mcp`                               | 用 stdio 提供 MCP。見 [Agent 工作流程](agent-workflow.zh-TW.md)    |
| `mapedit --help`                            | 列出指令                                                           |

`init` 不會覆寫已經存在的檔案，只會在已有的 `.gitignore` 裡補上缺少的行。

`check` 與 `export` 沒加 `--map` 時會處理全部地圖。任何一張有違規或檔案錯誤，`check` 就以非零代碼結束，
可以放進 git hook 或 CI。`export` 會在寫入任何檔案前全部拒絕，並列出有問題的地圖。`check --json` 固定回傳
同樣的格式，指定地圖時陣列只有一項：

```json
{ "maps": [{ "map": "village", "violations": [], "fileErrors": [], "floating": [] }] }
```

`floating` 列出所有 `canFloat` 模組的 ref、模組類型與世界座標，包含目前貼地的實例。這是提示資訊，不算違規。
MCP 的 `check` 和 `overview` 同樣預設檢查全部地圖。

範例，在專案資料夾裡執行：

```sh
node ../../packages/cli/dist/index.js check --map village --json
node ../../packages/cli/dist/index.js export --map village --out ./export
```

（`../../` 適用於放在 `projects/` 裡的專案，放在別處請自行調整。）
