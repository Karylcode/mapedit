# 模組外型：程式生成，加上匯入外部素材

模組的外型，不論形狀還是材質，都有同樣兩個來源：程式生成（Agent 寫成程式，由編輯器產生出來），以及從外部匯入的素材（素材包、生成式 AI 做的模型或貼圖等）。材質另外有一個內建的材質庫可以直接挑。程式生成保證尺寸精準、插槽位置正確，之後也能用一句話修改；外部素材補上程式生成做不好的細節，匯入時由編輯器校正到規定尺寸。生成式 AI 服務不內建在編輯器裡：Agent 需要時透過它自己的 MCP 呼叫，再把結果匯入。這樣編輯器維持不含 AI，也不綁定任何一家付費服務。

## Consequences

- 程式寫出來的貼圖在匯出前要先轉成圖片，因為 glTF 只認圖片貼圖，四個引擎看到的結果才會一樣。
