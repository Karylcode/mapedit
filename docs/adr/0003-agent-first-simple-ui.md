# Agent 優先，人的操作像玩 Minecraft 一樣簡單

這個編輯器主要給 Agent 用，其次才給人用。大部分的建造和建模由 Agent 完成；人在瀏覽器裡只做簡單直覺的事，例如把擺錯的東西拖回正確位置。做這個工具的起因，就是 Blender 和遊戲引擎的地圖編輯器太複雜、學習成本太高，所以人的介面刻意保持像玩 Minecraft 一樣簡單：不放數值參數面板，也不照搬專業編輯器的功能。需要精確或大量修改的事，交給 Agent。

人只有兩種視角：預設的俯瞰模式（看全貌、拖動東西修正），以及一鍵切換的第一人稱模式（像 Minecraft 創造模式那樣走動和建造）。兩者共用同一套快捷欄和吸附規則，操作只有快捷欄、點擊、拖曳和按鍵旋轉，不用三軸箭頭。
