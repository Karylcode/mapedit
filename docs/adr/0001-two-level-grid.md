# 兩層格子的空間模型

地圖要同時有 Minecraft 式的格子吸附和 Valheim／Palworld 式的插槽吸附，又要嚴格防止穿模、不留縫。所以採用兩層格子：地圖和每個結構各有一張 0.5 公尺的格子，結構內部的模組只轉 90 度並透過插槽對齊；整個結構擺在地圖的格點上，以 15 度為一段轉向。地形也用格子（1 公尺見方的地塊，高度以 0.5 公尺為一階），讓沒轉角度的地基剛好落在地塊上。

## Considered Options

- 整張地圖只有一張格子、一律轉 90 度：碰撞判斷最簡單，但房子沒辦法順著彎路排，失去 Valheim／Palworld 的手感。
- 位置和角度完全自由：最有彈性，但無法保證不留縫，Agent 也得處理小數和任意角度。

## Consequences

- 角度不同的結構之間，沒辦法只看格子有沒有被佔用來判斷碰撞，要用實際幾何形狀檢查。
- 轉了角度的地基不會對齊地塊，它和地形的接合方式見 [0008](0008-foundations-extend-down.md)。
